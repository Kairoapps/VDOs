# Caption voice

Edit this file to tune how captions sound. The daily run reads it before writing captions.

- **Every caption/description starts with "Download the Unsnooze app"** as its own first line, on every platform (TikTok, Instagram, Facebook, YouTube description), with the slot's caption after it. This line doesn't count toward the emoji count and the caption style applies to what comes after it.
- First person, casual, like texting a friend. Lowercase is fine.
- Lead with the most interesting thing; no "Hey guys" or "In this video".
- Short lines.
- No engagement bait ("comment YES if…"); questions should be real. Never ask people to comment a keyword ("comment UNSNOOZE…"): it was dropped 2026-11-25 because TikTok and YouTube can't send the DM.
- Emojis: use exactly the number the slot asks for (`post_emoji`: 0, 1, or 2–3), hashtags not counted. Vary them: don't default to 😭; pick ones that fit the challenge and mood (💀 😩 🫠 🥲 😤 🙄 🤡 ⏰ 📱 🧠 👟 📸 🔥…) and use different ones from post to post. For `2-3`, use different emojis rather than one repeated.
- Name the challenge's numbers: "walk 100 steps", "shake 67 times", "memorize 6 colors", "tap 60 times". Use the on-screen title's numbers or your own; playful exaggeration ("1000 steps") is good because people comment to call it out. Don't invent app features or claim clock times the clip doesn't show.
- Context: computer engineering student who builds apps; clips are first-person (Ray-Ban Meta glasses).

## Caption styles (the daily plan assigns one per slot; the weekly review learns which wins)

- `hook_cta`: a hook line, then a soft CTA ("unsnooze makes you actually get up. link in bio"). On YouTube say "link in description" only if the description has a link; otherwise "it's on the app store".
- `relatable`: one relatable line about the moment, no CTA ("me pretending i'll get up after one more snooze").
- `question`: one real question people want to answer ("what's the worst challenge you'd put on your alarm?").
- (`comment_cta` was retired 2026-11-25 — no "comment UNSNOOZE" asks anywhere.)
